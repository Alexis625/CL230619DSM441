# CECAM

Bienvenido al repositorio de nuestra aplicación educativa de CECAM, este proyecto está desarrollado en Kotlin con Firebase para Android Studio.

## Características

### Para Educadores
- *Creación de cuestionarios*.
- *Subida de notas y materiales*.
- *Seguimiento de asistencia*.
- *Compartir avisos importantes*.

### Para Estudiantes
- *Participar en cuestionarios*.
- *Gestión de perfil*.
- *Descarga de materiales*.
- *Notificaciones y avisos*.
- *Sala de chat para dudas*.


## Comenzar

1. Clona el repositorio.
2. Abre el proyecto en Android Studio.
3. Configura Firebase.
4. Ejecuta el proyecto en tu dispositivo Android.
